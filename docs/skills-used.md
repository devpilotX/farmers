# Repository skills used

The original 58 skills remain in `skills/` unchanged. Relevant instructions were loaded directly from this repository for this foundation. They were not replaced with generic templates or copied into Notion pages.

| Skill | Applied to |
| --- | --- |
| codebase-onboard | Distinguishing the blueprint and prototype from a running application |
| build-pilot | Restricting delivery to the foundation and three vertical workflows |
| arch-decide | Recording the supplied stack and release boundaries before implementation |
| ui-design, design-system | Concrete type, spacing, colour and state rules; one stylesheet for one app |
| frontend-build | React boundaries, API failures, keyboard forms and mobile navigation |
| backend-build, data-layer | Organisation isolation, input validation, transactions, retries and migrations |
| code-craft | Separating transport, business decisions, storage and presentation |
| test-strategy | Real PostgreSQL integration tests and complete browser journeys |
| accessibility-audit | Automated scans, keyboard interaction, reflow and visual inspection |
| security-hardening | Identifier swaps, scope checks, safe errors and a restricted demo profile |
| code-review, ship-audit | Correctness review and explicit production blockers |
| git-discipline | Feature branch, focused publication and a reviewable pull request |
| doc-forge, human-prose | Runnable documentation, specific limits and a prose-style check |

Unrelated skills such as payments, email delivery and job search were not invoked. A plain writing style does not establish human authorship; no such claim is made.
